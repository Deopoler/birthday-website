# 하진 순장님 생일 축하 사이트 🎂

봉투를 열면 밤하늘에 '이하진' 모양 별자리가 나타나고, 별을 누르면 친구들의 롤링페이퍼 편지가 열려요. 아래로 내리면 포스트잇 사진판이 나와요. 휴대폰 화면에 맞춰 만들었어요.

- 주소: https://deopoler.github.io/birthday-website/
- 내용(메시지·사진)은 `src/data/messages.js` 파일과 `photos/` 폴더만 바꾸면 돼요. 지금은 더미(가짜) 내용이에요.

## 1. 메시지 바꾸기 — `src/data/messages.js`

파일 전체를 아래처럼 바꿔 쓰세요. `id`는 0부터 차례로, `from`은 보내는 사람, `text`는 편지 내용이에요.

```js
export const messages = [
  { id: 0, from: '민수', text: '순장님, 생일 축하드려요! 항상 감사해요.' },
  { id: 1, from: '지연', text: '오늘 하루 제일 행복하세요 🎂' },
  // ... 같은 모양으로 계속
]
```

**메시지는 정확히 30개**로 맞추세요. 이름 '이하진' 모양 별이 30개예요.

- 30개 미만: 메시지 수만큼만 별이 켜져요. 나머지 자리는 비고 글씨 획 일부가 완성되지 않으며, 카운터가 `★ 0 / 25`처럼 그 개수로 보여요.
- 30개 초과: 31번째부터는 화면에 나오지 않아요(무시돼요).

## 2. 사진 넣기 — `photos/` 폴더

코드를 수정할 필요 없이 **`photos/` 폴더에 사진 파일만 넣으면** 자동으로 크기를 줄이고 사진 비율에 맞춘 포스트잇으로 화면에 나타나요. (`photos/` 폴더가 비어 있으면 기본 색상 더미 12장이 보여요.)

1. 저장소 맨 위의 **`photos/` 폴더**에 사진 파일들을 넣어요.
   - 파일 이름은 한글·영어·숫자 아무거나 괜찮아요.
   - 화면에 나오는 순서는 **파일 이름 순서(자연 정렬: 1, 2, 10 순)**예요. 원하는 순서가 있다면 `01_바다.jpg`, `02_카페.jpg`처럼 앞에 숫자를 붙여 주세요.
2. **(권장) 원본 크기 줄이기·위치 정보 지우기**: 터미널에서 아래 명령을 한 번 실행하세요.
   ```bash
   npm run photos:shrink
   ```
   - 휴대폰·카메라 원본 사진은 한 장에 수 MB씩 나가고 **찍은 장소(GPS 위치 정보)**가 들어 있는 경우가 많아요. 이 저장소는 **공개(public)**되어 있어 올린 파일이 그대로 공개되므로, `git push` 전에 꼭 실행하는 것을 권장해요.
   - 이 명령을 실행하면 큰 사진(긴 변 2000px 초과, 1.5MB 초과, 또는 GPS 포함)만 골라 용량을 줄이고 위치 정보를 모두 지워 같은 파일명으로 바꿔 줘요. 원래 파일은 지워지지 않고 `photos-originals/` 폴더(Git에 올라가지 않음)에 안전하게 보관돼요.
   - 혹시 이 명령을 건너뛰어도 실제 웹사이트에는 자동으로 작게 줄이고 메타데이터를 지운 사진만 올라가요.
3. **내 컴퓨터에서 미리보기**: `npm install`(처음 한 번) → `npm run dev` → 터미널에 나온 주소를 열면 바로 확인할 수 있어요. 서버를 켜 둔 채로 사진을 넣거나 빼도 화면에 바로 반영돼요.
4. **사이트에 올리기**:
   ```bash
   git add -A
   git commit -m "사진 추가"
   git push
   ```
   1~2분 뒤 GitHub Actions 배포가 끝나면 사이트에 나타나요.

- **지원 형식**: `JPG`(`.jpg`, `.jpeg`), `PNG`(`.png`), `WebP`(`.webp`), `AVIF`(`.avif`), `GIF`(`.gif`, 첫 프레임)
  - ⚠️ 아이폰 **HEIC(`.heic`, `.heif`) 파일은 그대로 읽지 못해요.** 윈도우 '사진' 앱에서 열기 → '다른 이름으로 저장'에서 `JPG`로 바꿔 넣어 주세요.
- **사진 개수**: 제한은 없지만, 화면이 보기 좋고 빠르게 열리도록 **6~20장 정도**를 권장해요.

## 3. 반영하기

- 내 컴퓨터에서 미리보기: `npm install` 한 번 → `npm run dev` → 터미널에 나온 주소 열기.
- 사이트에 올리기: 파일을 고치고 `git add .` → `git commit -m "내용 교체"` → `git push` (`main` 브랜치). GitHub Actions가 자동으로 배포하고 1~2분 뒤 주소에 반영돼요.

## 4. 주의: 메시지가 소스에 그대로 보여요

저장소가 public이라 `messages.js`의 메시지를 누구나 볼 수 있어요. 생일 당일까지 숨기려면 더미로 두었다가 **당일에 진짜 내용으로 바꿔서 push**하는 게 가장 간단해요.
